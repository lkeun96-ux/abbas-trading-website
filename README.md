# ABBAS TRADING 웹사이트 (주식회사 아바스무역)

정적 웹사이트입니다. 서버·빌드 도구 없이 그대로 올리면 됩니다.

## 구성
```
abbas-website/
├── index.html                ← 실제 배포용 (HTML + CSS + JS 한 파일)
├── index-standalone.html     ← 미리보기·공유용 (사진까지 파일 안에 포함, 4.3MB)
├── images/
│   ├── hero-car.jpg          메인 배경 (Unsplash, 상업적 이용 무료)
│   ├── storefront.jpg        회사 전면 사진
│   ├── port.jpg              물류 섹션 배경 (Unsplash)
│   ├── parts01~14.jpg        부품 사진
│   ├── facility01~13.jpg     창고·현장 사진
│   ├── og-image.jpg          카톡·페북 공유 미리보기 (1200×630)
│   └── favicon-*.png         파비콘
└── README.md
```

## 두 파일 차이
- **`index.html`** — 실제 서버에 올리는 파일. 반드시 `images` 폴더와 **같은 위치에** 있어야 합니다.
  이 파일만 따로 떼어 옮기면 사진이 전부 깨집니다.
- **`index-standalone.html`** — 사진 30장을 파일 안에 넣은 버전. 이 파일 **하나만** 있으면
  어디서 열어도 사진이 나옵니다. 클라이언트 확인용으로 카톡·메일 전송할 때 사용하세요.
